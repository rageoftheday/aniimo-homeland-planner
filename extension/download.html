Install

  1. Download Aniimo_Homeland_Companion.zip.
  2. Extract the ZIP.
  3. Run Install_Companion.bat.
  4. The installer copies the extension to %LOCALAPPDATA%\\AniimoHomelandCompanion and opens that folder.
  5. Chrome / Edge extension settings will open when those browsers are installed.
  6. Turn on Developer mode.
  7. Click Load unpacked.
  8. Select the permanent AniimoHomelandCompanion folder opened in Explorer.
  9. Return to Aniimo Homeland Planner and refresh the page.
  10. For later versions, run Update_Companion.bat from the new ZIP, then click Reload on the extension card.
