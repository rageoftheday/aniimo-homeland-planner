Unlock filtering

The RV selector controls item availability and automatic placement caps. Items with unknown footprints show editable Width × Height boxes and cannot be placed until both are entered. Dimensions use 0.5-square increments. Farmland, Woodland, Mines, and other entries with RV cap data recalculate when RV changes. An item marked AUTO RV# is using that cap; editing Max Placeable changes it to MANUAL. Press Auto to restore the RV value. Plot access is controlled separately with Plot 1–16 checkboxes.

Plant availability

The site index contains more seed/material names than the normal Farmland/Woodland formula lists. This picker now follows the actual facility formulas by level. Special/event/index-only plants are not treated as normal growable formulas unless the current facility page lists them.

Production values

Crop/tree values are raw per-plot Home Coin/hour. The Supply / Demand Audit below now caps assigned processing by available upstream ingredients. It uses current crop formula quantities/work times plus the assigned Mine/Well and processor recipes. Recipe chains not yet present in the planner database are flagged instead of being guessed.
v30 worker rules use independently implemented game facts: station Home Ability, preferred personality letter, and known family-only recipe eligibility. Family locks currently include Susuta, Shelly, Nimbi, Iris, Dewy, Celestis and Flutternym evolution families. The v29 offline catalog is intentionally editable: verified presets autofill abilities, while not-yet-verified names remain blank rather than being guessed.
